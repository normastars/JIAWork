# CAC 导出数据接入与查数

当前查数使用嘉迪提供的 2026 年 CAC 导出文件，已导入本机 SQL Server 影子库 `JIAWorkCACShadow`。这是静态样本；文件中最晚记录为 2026 年 11 月 11 日。App 不连接 CAC 原库，数据库账号只有读取权限。

## 更新数据

将新导出的 CSV 放在同一目录，保持原文件名，在 JIAWork 仓库运行：

```sh
node scripts/import-cac-shadow.cjs /数据所在目录/sql_res
```

脚本会检查 8 份文件、处理描述字段里的换行和旧编码、启动本机 SQL Server 容器、导入影子库，并更新本机 App 的只读连接。`仓库出入库_2026.csv` 与 `出入库明细_2026.csv` 是同一批记录的不同排序，只导入后者一次。源文件和数据库密码不会进入 Git 仓库；密码仅保存在本机受限文件中。导入完成后重新启动 App。

数据模型由 JIAWork-Admin 发布。本机管理平台已经发布「嘉迪 CAC 2026 业务数据模型」；在其他环境首次安装时，Admin 会以仓库里的 `app/data-model.default.json` 初始化。已有平台若仍是旧演示模型，可在「数据模型 → 导入 / 导出」导入 JIAWork 的 `src/main/nlq/model.json`，保存草稿并发布。App 下次查数前会自动同步。

## 可查范围与口径

- 销售订单数、指定物料的销售明细数量；销售主表 `TOTAL_AMT` 全为 0，因此不开放销售金额。
- 采购订单数、采购订单金额、指定物料的采购明细数量；本批采购主表币种均为人民币。
- 指定产品的生产数量、指定物料的需求量、已发量和未发量；物料行本身没有日期，按对应生产单的最早 `DATE_FINSH` 归期。
- BOM 条目数、指定物料的仓库净出入库数量和仓库出入库金额净额。出入库数量是带正负号的流水净变动，**不是库存结存**。

数量指标必须指定物料或产品编号；采购明细数量还必须指定计量单位，因为样本中有少数物料出现多种单位。报价表在这批资料中没有记录，库存结存和采购未收也缺少可靠数据口径，因此没有发布这些指标。生产单日期的业务含义、各单据类型是否应纳入汇总，后续仍需嘉迪确认。

可先在「嘉迪专家」中问：“2026 年 10 月有多少张销售订单？”或“2026 年 10 月采购订单总金额是多少？” 本机导入数据的校验值分别是 **259 单**和 **33,129,571.81 元**。查询其他电脑上的 App 时，该电脑也需要能访问结构相同的影子库。
