# 嘉迪 AI 工作台企业配置

这个目录提供嘉迪一期工作台的内置企业配置。构建应用时，首页名称、说明、六个快捷任务和员工侧导航策略会直接打包进应用，不需要部署人员再复制配置文件。内置配置强制使用简体中文，跳过 LobsterAI 云账号入口、首次登录页和上游自动更新，关闭上游使用统计，员工直接进入工作台并按需配置企业模型。配置中不包含模型密钥、员工凭据或 ERP 地址。

## 安装包与数据兼容

安装包对外显示“嘉迪 AI 工作台”并使用嘉迪图标。应用 ID、可执行文件名 `LobsterAI`、macOS 应用包文件名 `LobsterAI.app` 和用户数据目录保留原值，以便现有安装脚本识别旧进程，并让升级后的应用继续读取历史会话和设置。macOS 的应用显示名称与系统权限提示已改为中文。

离线打包时可设置 `OPENCLAW_SKIP_OPTIONAL_PLUGINS=1`，跳过当前工作台验收未使用且网络无法获取的可选 IM 插件；必需插件仍由打包校验检查。

## 运行时扩展

后续需要接入模型、远程 MCP、企业技能或其他策略时，可将完整企业配置包放到 Electron 用户数据目录的 `enterprise-config`：

- macOS：`~/Library/Application Support/LobsterAI/enterprise-config/manifest.json`
- Windows：`%APPDATA%/LobsterAI/enterprise-config/manifest.json`

运行时配置会覆盖内置工作台的同名设置；没有提供的工作台字段继续使用嘉迪默认值。模型与远程 MCP 应在实际服务确定后加入企业配置包。不要把正式密钥提交到仓库。

## 快捷任务

- 表格分析：启用 `xlsx` 技能。
- 文档编写：启用 `docx` 技能。
- 工作总结：启用 `docx` 技能。
- 库存核对：核对账面、盘点或 ERP 导出文件，生成差异清单；启用 `gardy-inventory` 技能和其中的固定计算脚本。脚本将无对应记录与确认零库存分开标注。
- 采购交期跟进：比对订单、供应商确认和收货记录；启用 `xlsx` 技能。
- 质量异常整理：从检验和客诉材料生成可编辑草稿；启用 `docx` 技能。

快捷任务会自动选择对应助手和技能，并把经过约束的任务说明写入输入框，由员工补充材料后再执行。统计口径和业务事实仍以嘉迪确认的规则及输入材料为准。新场景只处理员工提供的文件；实时 CAC ERP、供应商系统或审批系统连接需要单独的接口和服务配置。

## 三个助手的系统提示词

表格分析、文档处理和工作总结专家分别从 `resources/gardy-prompts/` 下的三个 Markdown 文件加载系统提示词。提示词正文使用英文编写，但要求专家始终向员工输出简体中文。提示词覆盖汽车零部件业务中可能出现的表格、报价材料和汇报资料，同时要求以实际文件及嘉迪确认的口径为准，不把 CAC ERP 导出文件当成实时系统连接。

应用启动时，新安装的助手使用文件中的默认提示词；仍保留旧内置默认提示词的助手会自动升级。员工在应用内自行修改过的提示词会保留，不被默认文件覆盖。修改这三个源文件后需要重新构建应用。
